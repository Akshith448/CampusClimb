# CampusClimb: Academic Publication Strengthening & Evaluation Summary

This document summarizes the results of the academic evaluations implemented to address known weaknesses in the topic-mapping system of CampusClimb.

All evaluations are standardized on the **Clean-97 Model** (`fine_tuned_capt_m_clean`), trained on only 97 dev notes, to ensure peak accuracy and rigorous validation on the disjoint **229-sample held-out test split** (seed=42, 30% dev / 70% test) with zero training data leakage.

## 2. Reconciling Gated vs. Raw Accuracy
- **Force-Map / Raw Model (No Abstention):** Force-maps a topic for every note chunk. The Clean-97 Hybrid achieves a peak **64.63%** Top1 accuracy and **82.97%** Top3 accuracy.
- **Gated Model (Abstention Enabled):** Uses CAPT-M confidence thresholding and mixed-topic filters to predict `None` on ambiguous chunks. When counting all abstentions as incorrect, the Clean-97 Gated Hybrid achieves **61.57%** raw accuracy.
- **Decoupled Gated Metrics:**
  - **Coverage:** **91.70%** (210 / 229 chunks mapped)
  - **Accuracy-on-Covered:** **67.14%** (141 / 210 correct)
  - **Raw Accuracy:** **61.57%** (141 / 229)

## 4. True Component Ablation Study (Clean-97 Model)
We isolated each component of the CAPT-M pipeline sequentially using the fine-tuned (FT) Clean-97 embeddings:

| Configuration | Top1 Acc | Δ Top1 (pp) | Top3 Acc | Δ Top3 (pp) | Macro F1 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **1. FT SBERT NN only** | 0.6288 | — | 0.7773 | — | 0.4941 |
| **2. + complete-linkage clustering** | 0.5677 | -6.11% | 0.7729 | -0.44% | 0.4324 |
| **3. + keyword mixed-topic detection** | 0.5240 | -4.37% | 0.7031 | -6.98% | 0.4647 |
| **4. + confidence/adaptive threshold** | 0.5240 | +0.00% | 0.7118 | +0.87% | 0.4658 |
| **5. + TF-IDF hybrid stacking** | 0.4672 | -5.68% | 0.5983 | -11.35% | 0.4198 |

*Note: The raw Clean-97 Hybrid model achieves 64.63% Top1, representing a **+1.75pp** improvement over the FT SBERT NN base (62.88%), showing that simple hybrid lexical-semantic blending is the most effective stack for peak accuracy. In contrast, Configuration 5 (46.72% Top1) represents a cumulative sequential pipeline where clustering, keyword mixed-topic detection, and confidence thresholding are stacked together, leading to lower raw accuracy due to cumulative gating/abstentions (treated as incorrect) and cluster representative approximations.*
